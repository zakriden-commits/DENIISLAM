# Северный рубеж / Northern Frontier — Survival 0.3

**Полная замена прежней игры, а не перекраска tycoon.** Новая кооперативная
survival-альфа от первого лица для двух игроков: Deni и Islam. Банка, магазинов,
валюты, работ, розыска и старого городского интерфейса больше нет.

Это работающая развиваемая альфа на Three.js, не законченный коммерческий/AAA
продукт. Android — тестовый APK; iPhone — устанавливаемая веб-версия (PWA), не IPA.

## Что есть

- Территория 1024 × 1024 м: лес, рельеф, ручей, убежище, лесопилка, насосная,
  блокпост, покинутая деревня, бункер и радиовышка.
- Новый стартовый экран, русский survival-HUD, компас, топографическая карта
  с маршрутной меткой, рюкзак, создание предметов и общий ящик.
- Голод, жажда, холод, выносливость, цикл суток и периодический шквальный ветер/туман.
- Древесина с деревьев/сухостоя, камни, ягоды, обыск строений, ограниченные припасы.
- Костры расходуют дрова, согревают и отпугивают волков. Можно изготовить бинты,
  копьё и походный костёр, пожарить мясо, прокипятить набранную речную воду.
- Олени, волки и вооружённые мародёры; анимации животных из лицензированного пакета.
  Люди — скелетные модели с процедурным движением конечностей.
- Настоящий первый вид с руками/оружием, ближний бой, пистолет и дробовик,
  перезарядка, серверный расход патронов, проверка дистанции и линии видимости.
- Смерть возвращает в убежище без выданного заново снаряжения: рюкзак можно
  подобрать на месте гибели в течение 20 минут.
- Общая цель: принести к вышке **3 радиодетали + 4 металлолома + 1 топливо**.
  Детали находятся на лесопилке, насосной и в бункере. Оба игрока могут вносить
  материалы. После восстановления связи выживание продолжается.
- Один авторитетный сервер, максимум два игрока, видимые друг другу; PvP нет.
  Добыча, урон, инвентарь, таймеры и ремонт считаются сервером, а не клиентом.

## Реальный размер, не заполнители

В `public/assets/` находятся **42 используемых лицензированных файла** — около
**40,15 МБ оригинальных моделей, текстур, HDR и лесного звука**. Сжатый asset-пак
сам по себе больше 30 MiB. Это не APK-размер: итоговый размер APK отдельно
проверяется после Gradle-сборки скриптом `scripts/check-apk.mjs`.

CI **не публикует APK меньше 30 MiB (31 457 280 байт)** и проверяет, что каждый
из 42 файлов внутри APK совпадает с исходным Git blob SHA. Точный размер
конкретной сборки смотрите в GitHub Releases / шаге `Verify actual survival APK`.
Никаких пустых файлов, неиспользуемых DDS, дубликатов для веса или случайной музыки.

- Quaternius: Survival, Nature, Animals, Modular Men, Buildings Pack 2 — **CC0 1.0**.
- Babylon.js Assets contributors: PBR-карты земли/коры/листвы, четыре LOD дерева,
  HDR леса для освещения, пена ручья, зимний лесной ambience — **CC BY 4.0**.
- Oswald и Manrope — SIL OFL, уведомления включены в приложение.

Полная атрибуция: [`public/CREDITS.md`](public/CREDITS.md), в игре «О проекте».
Источники, лицензии, размер и закреплённые SHA: `public/assets/manifest.json`.
Воспроизведение оригинальных файлов: `python3 scripts/fetch-assets.py` (нужен `gh`).
Текстуры реально загружаются и используются; для экономии GPU-памяти разрешение
на телефоне ограничивается 1024 px, на компьютере — 2048 px. Геометрия леса
инстансируется; подробность широколиственных деревьев переключается по расстоянию.

## Как подключить двух игроков

1. Запустите один сервер или используйте **действующий** адрес хоста.
2. На обоих устройствах откройте ⚙ и укажите одинаковый **HTTPS-адрес сервера**.
3. Нажмите **«Проверить сервер»**. Проверяются `/api/health`, версия 0.3 и
   WebSocket `/online`; ошибки выводятся прямо в окне, без вечного молчания.
4. Введите одинаковый код комнаты, если сервер настроен с `ROOM_CODE`.
5. Первый выбирает Deni, второй Islam → «Начать вылазку».

В 0.3 добавлены короткая WebSocket-проверка перед входом, явное сообщение при
старой версии сервера, автоматический перенос устаревшего sandbox-default
на новый preview-адрес при обновлении. Пользовательский постоянный хост не
перезаписывается. Сохранённый адрес можно исправить вручную в настройках.

**Оба клиента нужно обновить до 0.3.** Протокол старой 0.2 намеренно не принимается:
новая игра имеет другой мир и инвентарь. Вместо тихого сбоя старому клиенту
приходит сообщение обновиться. Идентификатор Android-пакета сохранён для установки
обновления поверх старого APK, имя и иконка приложения заменены.

Переподключение: backoff 1–15 с, heartbeat, восстановление после foreground/online,
90-секундное резервирование места. Повторный вход своим профилем забирает старую
сессию без гонки двух сокетов. Профиль привязан к адресу сервера и выбранному герою.

### ВАЖНО: preview не является сервером 24/7

Ссылка `*.e2b.app` — **временная среда разработки**. Пока процесс и sandbox
работают, можно играть. Если среда остановилась, APK и переподключение не смогут
её запустить. Не обещаем «всегда онлайн» без отдельного размещения.

Рецепты постоянного хостинга подготовлены, **но автоматически не развёрнуты**:

- свой VPS/домен: `compose.hosted.yaml` + Caddy + постоянный volume;
- Render Starter: `render.yaml`, платный тариф с постоянным диском.

Никаких платежей или аккаунтов за пользователя не создаём. Для постоянной
работы нужен выбранный владельцем хост. Одна копия сервера, без автоскейлинга:
мир и подключения находятся в одном процессе.

```sh
# На своём VPS с Docker и доменом, DNS которого указывает на сервер:
cp .env.hosted.example .env
# Заполнить GAME_HOST и приватный ROOM_CODE; при необходимости TURN.
docker compose -f compose.hosted.yaml up -d --build
# В настройках ОБОИХ клиентов указать https://ваш-домен.
```

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение / обзор | WASD / мышь после нажатия на мир | Джойстик слева / провести справа |
| Бег | Shift | БЕГ |
| Удар / огонь | ЛКМ | ◎ (можно одновременно вести прицел) |
| Добыча / действие | E | РУКА |
| Перезарядка | R | R |
| Прыжок | Space | ↑ |
| Снаряжение / карта | Tab / M | РЮКЗАК / КАРТА |
| Оружие | 1–4 | Нижние слоты |
| Освободить мышь / меню | Esc | Название игры сверху |

При сборе ресурсов надо остановиться. Рецепты и использование припасов — в
рюкзаке. Общий ящик — слева у входа в убежище. Мир не замирает при открытии меню:
лучше отдыхать в безопасном месте. Микрофон необязателен, требует разрешения;
для некоторых мобильных сетей голосу понадобится настроенный TURN.

Android: современный System WebView с WebGL 2; минимальный SDK 23 сам по себе
не гарантирует совместимость старого GPU/WebView. iPhone: Safari → «Поделиться» →
«На экран “Домой”». PWA кэширует оболочку и ассеты, **но игра требует онлайн-сервер**.
Ручное испытание на физическом Android/iPhone пока не проведено.

## Разработка и проверка

```sh
npm ci
npm run dev                 # 0.0.0.0:3000, Vite middleware + backend
npm test                    # 30 тестов, включая настоящий WebSocket-сервер
npm run build
npm run test:browser         # отдельный backend :3177, временные сохранения
npm start                   # production, готовый dist/
npm run android:sync
# Java 21 + Android SDK 35:
cd android && ./gradlew assembleDebug
# Из корня:
node scripts/check-apk.mjs android/app/build/outputs/apk/debug/app-debug.apk
```

Браузерная регрессия проверяет два независимых профиля, FPS-интерфейс, движение
и обзор касаниями, крафт, карту, нативную прокрутку справочника и портретную
раскладку. Тест принудительно использует свой сервер до загрузки модулей, даже
если APK-сборка содержит внешний `VITE_SERVER_URL`; живые места игроков не занимает.
Скриншоты CI — артефакт `FPS-phone-checks`. Программный Chromium значительно
медленнее реального GPU; это функциональная проверка, не обещание FPS на телефоне.

Сохранения: `DATA_DIR/survival-save.json`, новая схема 3, атомарная запись раз в
10 секунд и при завершении. Старый `save.json` остаётся нетронутым, но старые
деньги/предметы **не переносятся**. Сохраняются личные припасы/статы/позиция,
общий ящик, костры, истощённые ресурсы, рюкзаки и вклад в радиовышку. Популяция
NPC создаётся заново при перезапуске процесса.

CI собирает и публикует debug-подписанный APK, web ZIP и SHA256SUMS в Releases.
Подписной ключ кэшируется для обновлений, но это не production-подпись Google Play.
Параметр сборки `VITE_SERVER_URL` / GitHub variable `GAME_SERVER_URL` задаёт адрес
по умолчанию для APK; в игре его можно поменять без пересборки.
