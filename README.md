# DENI ISLAM

**Двое против квартала.** Игровая 3D FPS low-poly альфа для двух настоящих игроков: Android (Capacitor APK), iPhone (устанавливаемая PWA) и ПК (браузер).

> Это рабочий первый прототип, а не законченная коммерческая игра. Модели города, персонажей и оружия — оригинальные процедурные low-poly модели. Размер не раздувается пустыми файлами. Постоянный сервер и доставка приложения через App Store в репозиторий не входят.

## Версия 0.2 — первое лицо и телефон

- Настоящая камера **от первого лица**, отдельные руки/кулаки/оружие, отдача, вспышка и перезарядка. Собственный персонаж перед камерой больше не виден; напарник видит вашу полную модель.
- Грубая ретро-графика: серый пасмурный квартал, потёртый бетон, низкое разрешение 3D при чётком интерфейсе. В меню **Экран** — три уровня качества и чувствительность взгляда.
- Android APK — горизонтальный fullscreen. Телефонный HUD учитывает вырезы и безопасные поля; крупные touch-кнопки. Бег переключается нажатием, по кнопке огня можно вести пальцем, одновременно стреляя и меняя взгляд. На iPhone поворот может потребовать отключить системную блокировку ориентации.
- **Автопереподключение** после сетевого сбоя, смены Wi-Fi/мобильной сети и возвращения из фона. Повторы с интервалом 1–15 секунд; есть «Повторить сейчас» и отмена.
- Сервер **90 секунд держит место и текущую вылазку**: позицию, розыск, инвентарь, задание. Персонаж на время обрыва заморожен. После истечения резерва или перезапуска хоста — обычный вход дома с сохранёнными вещами.
- Старое полуразорванное соединение заменяется новым без ошибки «профиль уже в игре». Два окна одного профиля не перехватывают друг друга бесконечно.
- Зависшие входные данные останавливаются за 0,5 секунды: игрок не убегает сам, если приложение свернули. Сервер симулирует 20 Hz, но шлёт состояние 10 Hz для экономии мобильного трафика.

### Почему возникало «сервер недоступен» и что НЕ исправляется кодом

Раньше клиент вообще не восстанавливал WebSocket после обрыва. Это исправлено и проверено как на модели обрывов, так и реальным сервером. Однако **временное окружение Arena может остановиться/уснуть**. Автопереподключение не запустит выключенный компьютер и не заменяет хостинг. Гарантия «всегда, даже без работающего сервера» для онлайн-игры невозможна.

**Постоянный сервер здесь не развёрнут и ни за какой хостинг автоматически не списываются деньги.** Для игры независимо от этой сессии нужен VPS/платный всегда включённый сервис с диском. Подготовлены:

1. **`compose.hosted.yaml`** — игровой сервер, HTTPS Caddy, автоматический перезапуск после падения процесса/перезагрузки VPS, постоянный volume сохранений. На своём VPS с Docker и доменом:

   ```sh
   cp .env.hosted.example .env
   # Запишите в .env GAME_HOST (домен) и личный ROOM_CODE; направьте DNS на VPS.
   docker compose -f compose.hosted.yaml up -d --build
   ```

   Откройте порты 80/443. Затем **в обоих приложениях** задайте новый HTTPS-адрес и код в «Адрес сервера и код комнаты». Никогда не выполняйте `down -v`, если хотите оставить сохранения. Автоперезапуск защищает процесс, но не от неоплаченного/выключенного хостинга или потери диска; делайте резервные копии.

2. **[Развернуть на Render (платный Starter + диск)](https://render.com/deploy?repo=https://github.com/zakriden-commits/DENIISLAM&branch=arena%2F01855df3-deniislam)** — blueprint `render.yaml` использует текущую рабочую ветку. Потребуются ваш аккаунт и подтверждение оплаты у провайдера. TURN для сложных голосовых сетей добавляется в окружение отдельно. Развёртывание в Render из этого окружения не выполнялось.

Обновите APK **поверх** старого, не удаляя приложение: debug-подпись сохранена в кеше CI, `versionCode` повышен до 2. Профиль остаётся прежним, пока не очищены локальные данные. Веб-версию обновите перезагрузкой страницы; старый APK сам не заменяет встроенный код новым.

## Поиграть сейчас

Временный сервер этой сессии: **https://3000-iwh0asiuilxeqaap6svjf.e2b.app**

1. Оба открывают **одну и ту же ссылку**. Один выбирает **Deni**, второй — **Islam**.
2. По желанию включите голос галочкой в главном меню, разрешите микрофон и нажмите **Играть**.
3. Вы появитесь на разных кроватях **одного дома**. Через 3 секунды закончится пробуждение.
4. У дверей появляется действие. Откройте дверь, найдите склад на карте, заработайте на экипировку.

**Этот адрес временный.** Когда окружение Arena остановлено, сервер недоступен. Чтобы играть постоянно, разместите один экземпляр сервера на своём хостинге (ниже). GitHub Pages сам Node.js/WebSocket-сервер не запускает.

## Android — APK

[Скачать сборки из Releases](https://github.com/zakriden-commits/DENIISLAM/releases) · [Статус GitHub Actions](https://github.com/zakriden-commits/DENIISLAM/actions)

Workflow **Build Deni Islam — APK and web** запускается при push в рабочую ветку или main:
- проверяет игровую логику и реальное соединение двух WebSocket-клиентов;
- собирает веб-версию и Android debug APK с Java 21 / Android SDK 35;
- публикует `Deni-Islam-Android-alpha.apk`, веб-архив и SHA-256 в prerelease;
- сохраняет артефакты на 30 дней, release-файлы остаются до удаления release.

Если Actions запрещены политикой аккаунта, сборку нужно разрешить в настройках GitHub. Это **тестовая debug-подпись**, не сборка для Google Play. Разрешите установку из выбранного источника только если доверяете этой сборке. Минимум Android 6, современный Android System WebView с WebGL 2; рекомендуется Android 10+ и горизонтальный экран. Сборка на реальном телефоне требует отдельной проверки.

По умолчанию первая альфа подключается к временному адресу выше. В главном меню **Адрес сервера и код комнаты** можно задать постоянный HTTPS-сервер. Адрес должен совпадать у обоих игроков. Для следующих сборок задайте repository variable `GAME_SERVER_URL` или input `server_url` в ручном запуске workflow.

Локально с Android SDK и Java 21:

```sh
npm ci
VITE_SERVER_URL=https://your-game-server.example npm run build
npx cap sync android
cd android
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

Не удаляйте приложение для обновления без резервной копии профиля: локальные данные содержат ключ игрока. Debug-ключ кешируется Actions, но при очистке кеша может смениться; такая сборка потребует переустановки. Для публичного выпуска нужен собственный постоянный signing key, не хранящийся в Git.

## iPhone — отдельная установка на экран «Домой»

1. Откройте **HTTPS-ссылку сервера** в Safari.
2. Нажмите **Поделиться → На экран «Домой» → Добавить**.
3. Запускайте Deni Islam с иконки. Друг может быть на Android или ПК.

Это PWA, **не `.ipa` и не App Store-приложение**. Интернет нужен для игры. Service worker кеширует оболочку, а не симулирует отсутствующий сервер. Микрофон требует HTTPS и разрешения Safari. Профили Safari и установленной PWA могут различаться — используйте одно и то же приложение для сохранения прогресса. Реальные iPhone/iPad в этой среде не тестировались.

`Deni-Islam-iPhone-Web.zip` — статический клиент для собственного HTTPS-хостинга; это не установочный файл iOS. Для статической публикации задайте `VITE_SERVER_URL` при сборке. Vite использует относительный base, поэтому клиент можно разместить и по пути `/DENIISLAM/`.

## Что реализовано

- Одна общая комната на **2 места**, разные роли и внешность, анимация ходьбы, сна, переноски и сбора денег.
- Общий дом, две кровати, открываемая дверь, **два личных шкафа по 15 предметов**.
- Город, прохожие нескольких типов, взгляды на игроков, магазин с продавцом и 3D-превью товаров, большой банк, кассир и два охранника.
- Задания на **три ящика** с оплатой **140–519 ₽**. NPC периодически предлагают подработку; взять задание можно у склада в любое время.
- Пистолет 650 ₽, ПП 1 800 ₽, патроны 45 ₽ за 24 шт., сумка 450 ₽, аптечка 120 ₽. Патроны покупаются и заряжаются отдельно.
- Инвентарь, кулак, оружие в руках, перезарядка 1,6 с, HP, стамина, бег, аптечки.
- Удержание у денег: **15 с / 5 пачек / 2 500–9 999 ₽** руками; **30 с / до 50 000 ₽** с экипированной сумкой. Сумма ограничена остатком банка.
- Просмотр сумки, вывод указанной суммы или всего; пачки перечисляются при выборе и действии.
- Поле зрения охраны и перекрытие обзора стенами. Показанное оружие или сбор денег в поле зрения охраны вызывает тревогу. Охранники бьют, полиция приезжает и преследует.
- **1–5 звёзд для каждого игрока отдельно**, спад по одной после 18 с без наблюдения. Повторное обнаружение сбрасывает таймер. Дружеский огонь запрещён серверной логикой.
- При смерти — потеря инвентаря, добычи и боезапаса; баланс и шкаф остаются. Возрождение дома.
- Серверные сохранения каждые **10 секунд**, при отключении и штатном завершении сервера; атомарная запись JSON. При аварии теряется максимум последний интервал, при потере диска — весь файл.
- Голос WebRTC с добровольным разрешением, подавлением эха и выключателем MIC. Играть можно без микрофона. Сигналинг идёт через игровой сервер.
- ПК и touch-управление, миникарта, большая карта, справка, установка PWA.

## Постоянный сервер

Требуется **один постоянно включённый Node.js 22-сервер**, HTTPS с поддержкой WebSocket и постоянный диск. Второй экземпляр сервера создаст отдельную комнату: **не масштабировать горизонтально**.

### Локальная разработка

```sh
npm ci
npm run dev
# http://localhost:3000 — 0.0.0.0, доступен также по LAN-адресу компьютера
```

Для телефона используйте LAN IP компьютера, не `localhost`. HTTP по LAN годится для базовой игры, но не для микрофона/установки на iPhone. Для внешних сетей нужен публичный HTTPS.

### Docker + HTTPS reverse proxy

```sh
cp .env.example .env
# Задайте свой ROOM_CODE в .env
# Затем:
docker compose up -d --build
```

Пример Caddyfile на собственном домене:

```caddy
play.your-domain.example {
    reverse_proxy 127.0.0.1:3000
}
```

Caddy предоставляет TLS и проксирует WebSocket. Контейнер слушает только loopback, наружу доступ идёт через Caddy. Данные находятся в named volume `saves`, файл `/data/save.json`. Сделайте резервное копирование volume; `docker compose down -v` удалит сохранения.

Альтернатива — `render.yaml`: **платный** persistent-диск и один экземпляр. Проверьте стоимость до развёртывания. Автоматически никакой платный сервис не создаётся.

### Конфигурация

| Переменная | Назначение |
|---|---|
| `PORT` | Порт, по умолчанию 3000 |
| `NODE_ENV=production` | Отдавать собранный `dist` вместо Vite |
| `DATA_DIR` | Постоянный каталог сохранений; по умолчанию `./data` |
| `ROOM_CODE` | Общий секретный код входа, обязательно задайте на публичном сервере |
| `RECONNECT_GRACE_MS` | Сколько держать место после обрыва, по умолчанию 90000 мс |
| `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` | Необязательный TURN для голоса через сложные NAT |
| `VITE_SERVER_URL` | Адрес сервера для сборки отдельного клиента/APK |

Без TURN голос работает только если удаётся прямое WebRTC-соединение (используется публичный STUN Google). **Надёжный голос между любыми двумя мобильными сетями без TURN не гарантируется.** TURN endpoint конфигурации доступен клиентам: для публичной эксплуатации используйте краткоживущие TURN credentials; текущая альфа рассчитана на частный сервер с двумя друзьями.

Микрофон нельзя намеренно оставлять включённым без возможности отключения. ОС/браузер определяет, когда повторно показывать запрос разрешения; приложение не может принудительно спрашивать каждый раз, если разрешение уже сохранено.

## Тесты и архитектура

```sh
npm test              # 33 unit/integration tests, в т.ч. реальные обрывы/повторный вход/сохранение
npm run test:browser  # изолированный сервер + Chromium, два клиента, touch и обе ориентации
npm run build         # production PWA
npm audit --omit=dev  # зависимости runtime
```

- `server/game.js` — авторитетная симуляция 20 Hz: движение, покупки, экономика, таймеры, бой, розыск, шкафы, сохранение.
- `server/index.js` — Express + WebSocket, лимит сообщений, heartbeat, атомарное сохранение, WebRTC-сигналинг.
- `src/shared.js` — единая геометрия/цены/коллизии для клиента и сервера.
- `src/world.js` — Three.js-город, процедурные модели, скелетная анимация групп, товары.
- `src/main.js`, `src/style.css` — интерфейс, управление, камера, карта и сетевой клиент.
- `src/connection.js` — WebSocket heartbeat, ограниченные интервалы повторов, watchdog и восстановление при возврате в приложение.
- `src/first-person.js`, `src/mobile.css` — FPS-руки, отдача, передний 3D-проход, мобильный интерфейс и настройки.
- `src/voice.js` — WebRTC и управление разрешённым микрофоном.
- `android/` — нативная оболочка Capacitor с разрешением микрофона и landscape/fullscreen.
- `tests/browser-check.js` / `tests/browser-ci.js` — изолированный headless тест двух клиентов, landscape/portrait, настоящие touch-события и настройки; оригинальный сервер с игроками не затрагивается. Chromium и вспомогательные библиотеки берутся из установленного npm-пакета без внешнего CDN. В Actions сохраняются скриншоты.

Ограничения альфы: простой локальный AI и hitscan-бой, нет сложного navmesh/физики автомобилей, кат-сцен, транспорта под управлением, переноса профиля между устройствами, серверного аккаунта с восстановлением, матчмейкинга, App Store/Google Play-публикации и обещаний AAA-графики. Интерьеры открываются только у дома, банка и магазина. Баланс и сложность требуют дальнейшего playtest на двух физических телефонах.
